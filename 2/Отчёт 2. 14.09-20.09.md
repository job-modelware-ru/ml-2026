# Отчёт о проделанной работе

## Что сделано

- **Определены общие черты UI веб-приложения.**  
  Сформирован предварительный макет интерфейса: панель управления параметрами потенциала (высота, ширина, энергия, тип), основная область для анимации волнового пакета, дополнительные графики (вероятность прохождения, коэффициент прохождения), а также опциональный режим сравнения с аналитическим решением.

- **Начаты поиски подходящей архитектуры нейросети.**  
  Рассматриваются варианты архитектуры для PINN: количество слоёв, нейронов, функции активации. Пока нет окончательного выбора.

- **Оценивается необходимый размер датасета (точек коллокации).**  
  Анализируются требования к количеству точек внутри области, на границах и в начальный момент времени. Точный объём пока не определён.

- **Продуман общий план дальнейших работ.**  
  Зафиксированы ключевые этапы: выбор архитектуры, генерация данных, обучение PINN, интеграция с веб-приложением, валидация.

## Текущий статус

- UI: концепция готова, детальная верстка не начата.
- PINN: архитектура в процессе подбора.
- Данные: оценка размера выборки продолжается.
