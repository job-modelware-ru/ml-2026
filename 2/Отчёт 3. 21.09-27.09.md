# Отчёт о проделанной работе

## Что сделано

- **Создан и оформлен репозиторий проекта.**  
  Репозиторий доступен по ссылке: [https://github.com/AnastasiaHudina/QuantTunnel](https://github.com/AnastasiaHudina/QuantTunnel).

- **Подготовлен `README.md` с полной физической постановкой.**  
  В документе выписаны:
  - уравнение Шрёдингера и переход к системе уравнений для $u$ и $v$;
  - потенциалы барьера и ямы;
  - начальное условие (гауссов волновой пакет);
  - граничные условия;
  - аналитические формулы для коэффициента прохождения $D$;
  - тест свободного движения $V=0$.

  Для каждой формулы указаны источники: учебник [1] и задачник [2].

- **Начата работа над моделью в DeepXDE.**  
  Изучены примеры использования `dde.data.TimePDE` для решения времязависимых PDE и рассмотрена структура кода для системы уравнений относительно $u$ и $v$.
