# Отчёт за 28.09–04.10

**Проект:** «Распознавание окружающих звуков»  
**Команда:** 8

## 1. Цель работы за отчётный период

Улучшить качество классификации звуков ESC-50, подобрать параметры наиболее
перспективных моделей без использования тестовой части данных и выбрать
основную модель для дальнейшей интеграции в веб-приложение.

## 2. Что было сделано

### 2.1. Улучшенное представление аудио

- Сохранён исходный набор из 154 признаков как воспроизводимый baseline.
- Реализовано расширенное представление из 424 признаков.
- К исходным признакам добавлены среднее значение и стандартное отклонение для
  каждой из 128 полос log-mel-спектрограммы.
- Добавлены статистики семи полос spectral contrast, описывающие разницу между
  спектральными пиками и минимумами.
- Реализована корректная обработка полностью тихих записей и аудио с невысокой
  частотой дискретизации.
- Для расширенных признаков добавлен отдельный проверяемый локальный кэш,
  который автоматически пересоздаётся при изменении схемы признаков.

### 2.2. Подбор модели

- Для подбора использованы только fold 1–4 набора ESC-50, всего 1 600 записей.
- Каждый из четырёх fold по очереди использовался как валидационный, а остальные
  три — как обучающие.
- Fold 5 был полностью исключён из подбора признаков и параметров и использован
  только один раз для финальной оценки выбранной модели.
- Сравнены исходное и расширенное представления аудио.
- Для RBF SVM проверены значения `C`: 1, 10, 30 и 100, а также варианты
  параметра `gamma`: `scale`, `auto`, 0,001 и 0,01.
- Для случайного леса проверены два способа выбора признаков в узлах и значения
  `min_samples_leaf`, равные 1 и 2. Во всех вариантах использовано 500 деревьев.
- Основной метрикой подбора выбран macro F1.

### 2.3. Анализ результатов

- Лучшим вариантом по кросс-валидации стал RBF SVM с расширенными признаками,
  `C=10` и `gamma="scale"`.
- Средний macro F1 выбранного варианта на четырёх валидационных fold составил
  0,5939 со стандартным отклонением 0,0227.
- На отложенном fold 5 построена нормализованная матрица ошибок.
- Сохранены precision, recall и F1 для каждого из 50 классов.
- Сформирована отдельная таблица наиболее частых ошибочных пар классов.
- Добавлена воспроизводимая команда `uv run train-improved`, выполняющая
  извлечение признаков, подбор модели и сохранение всех результатов.

### 2.4. Проверка качества кода

- Добавлены тесты расширенного извлечения признаков для обычного сигнала и
  полной тишины.
- Добавлены тесты, проверяющие создание четырёх валидационных разбиений и запрет
  попадания fold 5 в подбор параметров.
- Все 7 автоматических тестов успешно проходят.
- Статический анализ и проверка форматирования Ruff проходят без замечаний.

## 3. Полученные результаты

### 3.1. Сравнение с baseline на fold 5

| Модель | Представление | Признаков | Accuracy | Macro F1 |
|---|---|---:|---:|---:|
| Исходный RBF SVM | baseline | 154 | 0,5525 | 0,5410 |
| Выбранный RBF SVM | улучшенное | 424 | **0,6250** | **0,6037** |

Расширенное представление увеличило accuracy на 0,0725, а macro F1 — на
0,0627. На тестовом fold модель правильно классифицировала 250 из 400 записей.
Среднее время классификации одной записи по заранее извлечённым признакам
составило около 0,25 мс. Время извлечения признаков в эту величину не входит.

### 3.2. Сравнение кандидатов при подборе

Лучший RBF SVM с расширенными признаками получил средний macro F1 0,5939.
Лучший случайный лес на тех же признаках получил 0,5620. Для исходных 154
признаков лучшие значения составили 0,5208 для RBF SVM и 0,5140 для случайного
леса. Это показывает, что основной прирост получен не только за счёт настройки
параметров, но и за счёт сохранения более подробной информации о распределении
энергии по частотам.

### 3.3. Анализ ошибок

Лучше всего на fold 5 распознавались классы `airplane`, `crow`, `toilet_flush`,
`glass_breaking` и `rain`: их F1 находится в диапазоне от 0,8889 до 0,9412.

Наиболее сложным оказался класс `fireworks`: ни одна из восьми записей не была
распознана правильно, четыре из них модель отнесла к `pig`. Низкий F1 также
получен для `mouse_click`, `breathing`, `helicopter`, `pig` и
`door_wood_creaks`. Среди частых ошибок встречаются пары `frog` → `dog`,
`mouse_click` → `crackling_fire`, `chirping_birds` → `crickets` и
`washing_machine` → `wind`.

Несмотря на сохраняющиеся ошибки отдельных классов, выбранная модель заметно
превосходит baseline по обеим основным метрикам и выбрана в качестве основной
модели приложения.
