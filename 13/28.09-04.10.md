# Отчёт команды 13 за 28.09–04.10

## Тема проекта

**Прогнозирование температуры в Афганистане с использованием методов машинного обучения**

## Выполненная работа

1. Выбрана тема проекта по машинному обучению.

2. Тема проекта согласована с преподавателем.

3. Определена основная цель проекта:
   разработать работающее web-приложение для прогнозирования температуры в городах Афганистана с использованием ML-модели.

4. Составлен предварительный план проекта.

5. В качестве источника климатических данных выбран набор данных ERA5-Land.

6. Загружены климатические данные за период 2010–2025 гг.

7. Для проекта выбраны следующие параметры:
   - температура воздуха;
   - температура точки росы;
   - относительная влажность;
   - атмосферное давление;
   - количество осадков.

8. Исходные данные были преобразованы в CSV-формат для дальнейшей обработки и обучения модели.

9. Подготовлен набор данных для нескольких городов Афганистана.

## Следующий этап

На следующем этапе планируется:

- проверить и очистить данные;
- провести первичный анализ данных;
- подготовить обучающую и тестовую выборки;
- обучить первую ML-модель для прогнозирования температуры;
- оценить качество полученного прогноза;
- начать подготовку web-приложения для интеграции модели.
