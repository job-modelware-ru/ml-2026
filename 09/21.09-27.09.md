# Отчет за вторую неделю разработки детектора пилообразных колебаний на основе МО

На второй неделе было принято решение временно отложить отдельное направление с real-time детектированием и сосредоточиться на базовом офлайн-классификаторе кандидатов. К real-time ветке планируется вернуться после того, как будет полностью подготовлена многоканальная обучающая выборка и проверена работа обычного классификатора.

На первой неделе были проанализированы исходные данные и сформулирована общая архитектура детектора. На второй неделе основной задачей стал переход от этих идей к конкретным программным структурам и воспроизводимым промежуточным данным. В данном отчете рассматриваются фиксация профиля каналов и признаков, загрузка многоканальных сигналов, их выравнивание, разделение разрядов и получение автоматической псевдоразметки.

## Цели второй недели

- Зафиксировать первую рабочую версию профиля диагностических каналов и схему многоканального вектора признаков
- Реализовать загрузку сигналов с сохранением их исходных временных сеток
- Реализовать выравнивание каналов и явную обработку пропусков
- Сформировать список разрядов и разделить его на обучающую и проверочную части
- Получить файл псевдоразметки, сформированной алгоритмическим детектором, и подготовить связь этой разметки с кандидатами POSR и CPD. Возможность экспертной корректировки разметки предполагается рассмотреть отдельно чуть позже (посмотрим по результатам работы на псевдоразметке)

## Фиксация профиля каналов и схемы признаков

На первой неделе был определен общий набор диагностик, которые потенциально можно использовать. На второй неделе он был оформлен как фиксированный программный профиль. Для каждого канала в профиле задаются точное имя в SHT-файле, короткий программный идентификатор, физическая группа и способ выравнивания по времени.

Перед фиксацией профиля был проверен состав нескольких разрядов из разных категорий:

- В `easy/sht46699.SHT` найдено 65 каналов, из которых в полный профиль входят 23 из 24
- В `medium/sht42465.SHT` найдено 77 каналов, из которых в полный профиль входят 22 из 24
- В `hard/sht43838.SHT` найдено 63 канала, из которых в полный профиль входят 22 из 24
- В `notSaw/sht38596.SHT` найдено 88 каналов, из которых в полный профиль входят 17 из 24

Полный профиль состоит из следующих 24 каналов.

SXR-каналы:

- `SXR 27 мкм`

Диагностика D-alpha:

- `D-alfa  хорда R=50 cm`
- `D-alfa  хорда R=42 cm`
- `D-alpha (на столб)`

МГД-зонды:

- `МГД наружный`
- `МГД быстрый зонд рад.`
- `МГД быстрый зонд тор.`

Положение плазмы:

Напряжения:

Проверка показала, что общее количество записанных каналов само по себе не гарантирует наличие каналов полного профиля. Например, в нескольких разрядах отсутствует `SXR 27 мкм`, в отдельных файлах нет `SXR 127 мкм`, `U PF3` или части МГД-зондов. Поэтому состав входного вектора не формируется заново для каждого файла: порядок признаков остается постоянным, а отсутствие канала обрабатывается явно.

В коде зафиксированы три варианта карты признаков:

- `reference_sxr` — только 16 исходных признаков формы кандидата на опорном SXR-сигнале
- `core_diagnostics` — опорный SXR, признаки по всем SXR-каналам и 11 основным каналам из групп тока плазмы, D-alpha и МГД; всего 154 признака
- `full` — полный вариант с пятью SXR-каналами и 19 дополнительными диагностическими каналами; всего 218 признаков

Основной рабочей версией многоканального профиля является `full`. Его 218 признаков имеют следующую структуру:

- 16 признаков формы кандидата на опорном SXR-сигнале
- 55 признаков по пяти SXR-каналам
- 114 признаков по 19 дополнительным диагностическим каналам
- 28 агрегированных признаков по физическим группам каналов
- 5 признаков, описывающих происхождение кандидата

Ниже перечислены все уникальные типы признаков и приведены правила их вычисления. Полное имя каждого столбца включает название блока и конкретного канала или группы, поэтому даже одноименные величины из разных сигналов остаются разными признаками. Скрытых или неописанных столбцов в схеме нет.

### Общие обозначения и нормализация

Пусть `i` - индекс кандидата, `T` - оцененный период пилообразных колебаний, `dt` - шаг опорной временной сетки, а `eps` = $10^{-12}$ - малая константа, предотвращающая деление на ноль. Для признаков всех SXR-каналов, кроме отдельного базового блока опорного SXR, и для дополнительных диагностик используется робастная нормализация. По всем валидным отсчетам канала внутри плазменного интервала вычисляется масштаб

`scale = 1.4826 × median(|x − median(x)|)`.

После этого сигнал преобразуется по формуле

`z = (x − median(x)) / scale`.

Если MAD вырожден, вместо него используется стандартное отклонение, а если вырождено и оно - единица. Такая нормализация выполняется для каждого канала независимо и позволяет сопоставлять признаки сигналов с разными физическими единицами и амплитудами. Окно делится на участок `pre` до кандидата и участок `post`, начинающийся с отсчета кандидата. Для вычисления числовых признаков в каждой части требуется не менее трех валидных отсчетов.

### Признаки опорного SXR-сигнала: 16 признаков

Полные имена этого блока имеют вид `sxr__<имя признака>`. Блок вычисляется только для опорного SXR-канала (опорный SXR-канал выбирается автоматически по максимальному отношению сигнал/шум). Для первых пяти признаков используются асимметричные участки около кандидата. Длительность участка до события равна `clip(0.18 × T, 50 мкс, 700 мкс)`, после события — `clip(0.12 × T, 50 мкс, 700 мкс)`. Для остальных статистик используется симметричный сегмент с радиусом `clip(0.25 × T, 0.2 мс, 2 мс)`, но не менее 10 отсчетов.

1. `sxr__physics_score` — объединенная физическая оценка кандидата:
   `max(0, amp_score) + 0.15 × slope_score`.
2. `sxr__amp_score` — величина доминирующего скачка, нормированная на робастный разброс значений в локальном окне. Доминирующим считается максимум из обычного падения и инвертированного роста.
3. `sxr__slope_score` — наибольшая по модулю локальная производная, нормированная на robust-разброс производной.
4. `sxr__normal_drop` — оценка обычного падения сигнала:
   `percentile90(pre) − percentile10(post)`.
5. `sxr__inverted_rise` — оценка инвертированного роста:
   `percentile90(post) − percentile10(pre)`.
6. `sxr__seg_mean` — среднее значение локального сегмента.
7. `sxr__seg_std` — стандартное отклонение значений локального сегмента.
8. `sxr__seg_mad` — robust-разброс локального сегмента:
   `1.4826 × median(|seg − median(seg)|)`.
9. `sxr__seg_peak_to_peak` — полный размах локального сегмента:
   `max(seg) − min(seg)`.
10. `sxr__min_derivative` — минимальное значение производной в локальном сегменте.
11. `sxr__max_derivative` — максимальное значение производной в локальном сегменте.
12. `sxr__std_derivative` — стандартное отклонение производной в локальном сегменте.
13. `sxr__kurtosis` — коэффициент эксцесса локального сегмента в определении Pearson. Он характеризует выраженность выбросов и остроту распределения значений.
14. `sxr__skew` — коэффициент асимметрии распределения значений локального сегмента.
15. `sxr__post_minus_pre_mean` — изменение среднего уровня после кандидата:
    `mean(post) − mean(pre)`.
16. `sxr__post_std_over_pre_std` — отношение стандартного отклонения после кандидата к стандартному отклонению до него:
    `std(post) / (std(pre) + eps)`.

Если при вычислении этого блока получается `NaN` или бесконечность, значение заменяется на ноль. Это поведение относится именно к базовым 16 признакам опорного SXR.

### Признаки пяти SXR-каналов: 5 × 11 = 55 признаков

Одинаковый набор вычисляется для `SXR 15 мкм`, `SXR 27 мкм`, `SXR 50 mkm`, `SXR 80 mkm` и `SXR 127 мкм`. Полное имя столбца имеет вид `sxr_channel__<имя SXR-канала>__<имя признака>`.

Для каждого SXR-канала используются следующие 11 признаков:

1. `present` — индикатор наличия канала в рассматриваемом разряде: `1`, если канал загружен, иначе `0`.
2. `proposed` — индикатор того, что данный канал участвовал в формировании объединенного кандидата.
3. `proposed_posr` — индикатор наличия POSR-предложения на данном канале.
4. `proposed_cpd` — индикатор наличия CPD-предложения на данном канале.
5. `median_delta_z` — изменение медианного уровня robust-нормированного сигнала:
   `median(post) − median(pre)`.
6. `signed_jump_z` — величина и направление доминирующего скачка. Сначала вычисляются
   `drop = max(percentile90(pre) − percentile10(post), 0)` и
   `rise = max(percentile90(post) − percentile10(pre), 0)`.
   Если `drop ≥ rise`, признак равен `−drop`, иначе он равен `rise`. Поэтому падение имеет отрицательный знак, а рост — положительный.
7. `log_energy_ratio` — логарифм отношения RMS-энергии после и до кандидата:
   `log((RMS(post) + eps) / (RMS(pre) + eps))`.
8. `max_abs_period_slope` — максимальный по модулю перепад между соседними нормированными отсчетами, приведенный к длительности периода:
   `max(|Δz|) × T / dt`.
9. `change_offset_period` — положение наиболее сильного локального перепада относительно кандидата, выраженное в долях периода:
   `(i_change − i) × dt / T`.
10. `local_noise_z` — робастный разброс соседних разностей внутри участков `pre` и `post`:
    `1.4826 × median(|Δz − median(Δz)|)`.
    Разность непосредственно через границу кандидата в оценку шума не включается.
11. `log_jump_to_noise` — логарифмическое отношение изменения медианного уровня к локальному шуму:
    `log1p(|median_delta_z| / (local_noise_z + eps))`.

Если SXR-канал отсутствует, четыре индикатора `present`, `proposed`, `proposed_posr` и `proposed_cpd` равны нулю, а семь числовых характеристик отмечаются как `NaN`.

### Признаки дополнительных диагностических каналов: 19 × 6 = 114 признаков

Для каждого из 19 дополнительных каналов формируется одинаковый набор из шести признаков. Пока что он минимален и носит формальный характер - тут надо будет ещё подумать в процессе работы и адаптировать набор для каждой из групп (возможно, посоветоваться с экспертом) в зависимости от физического смысла(!). Полное имя имеет вид `channel__<ключ канала>__<имя признака>`. Используются следующие ключи:

- `ip_new`, `ip_internal`;
- `dalpha_lower_dome`, `dalpha_upper_dome`, `dalpha_r50`, `dalpha_r42`, `dalpha_column`;
- `mhd_outer`, `mhd_fast_radial`, `mhd_fast_toroidal`, `mhd_fast_vertical`;
- `plasma_shift`;
- `emission_electrode_voltage`, `beam_voltage`, `up_inner`, `up_outer`, `u_pf3`;
- `radiometer_8mm`;
- `diamagnetic`.

Для каждого из этих каналов вычисляются:

1. `coverage` — доля валидных отсчетов в полном локальном окне около кандидата. Значение находится в диапазоне от 0 до 1.
2. `median_delta_z` — разность медиан нормированного сигнала после и до кандидата.
3. `signed_jump_z` — доминирующее падение со знаком минус либо доминирующий рост со знаком плюс.
4. `log_energy_ratio` — логарифм отношения RMS-энергии после и до кандидата.
5. `max_abs_period_slope` — максимальный соседний перепад нормированного сигнала, приведенный к периоду пилы.
6. `change_offset_period` — временное смещение наиболее сильного перепада относительно кандидата в долях периода.

Формулы последних пяти признаков полностью совпадают с одноименными SXR-признаками. Если до или после кандидата имеется менее трех валидных отсчетов, `coverage` сохраняется, а остальные пять значений отмечаются как `NaN`.

### Агрегированные признаки физических групп: 7 × 4 = 28 признаков

Дополнительные каналы объединены в семь групп: `plasma_current`, `d_alpha`, `mhd`, `plasma_position`, `voltage`, `radiometer` и `diamagnetic`. Тут аналогично - подумать над разделением и уточнением признаков, пока что они формальные. Для каждой группы создаются четыре столбца с именами вида `group__<имя группы>__<имя признака>`:

1. `coverage` — среднее значение `coverage` всех каналов группы. Отсутствующие каналы имеют нулевое покрытие и поэтому учитываются в среднем.
2. `median_delta_z` — медиана всех конечных значений `median_delta_z` внутри группы.
3. `max_abs_jump_z` — максимальный модуль конечных значений `signed_jump_z` внутри группы.
4. `max_abs_period_slope` — максимальный модуль конечных значений `max_abs_period_slope` внутри группы.

При вычислении медианы и максимумов значения `NaN` не учитываются. Если в группе нет ни одного конечного значения соответствующего признака, групповой признак также равен `NaN`.

### Признаки происхождения кандидата: 5 признаков

Эти признаки описывают не форму отдельного сигнала, а совокупность исходных предложений, объединенных в один кандидат. Полные имена имеют префикс `proposal__`:

1. `proposal__source_channel_count` — число различных SXR-каналов, на которых был предложен кандидат.
2. `proposal__method_count` — число различных методов, сформировавших исходные предложения, например POSR и CPD.
3. `proposal__proposal_count` — полное количество отдельных предложений, объединенных в кандидат. Несколько предложений могут поступить с одного канала или от разных методов.
4. `proposal__median_log_source_score` — медиана преобразованных оценок исходных предложений:
   `median(log1p(max(score, 0)))`.
5. `proposal__time_spread_period` — разность между самым поздним и самым ранним предложением, нормированная на период пилы:
   `(t_max − t_min) / T`.

## Загрузка сигналов с исходными временными сетками

Каналы одного SHT-файла могут иметь разные временные сетки. В исследованных разрядах среди каналов полного профиля встречаются два характерных шага дискретизации: 1 мкс и 10 мкс. Кроме различия шага, начало и конец записи отдельных диагностик также могут не совпадать. Поэтому каждый канал загружается как самостоятельная запись, содержащая:

- Точное имя канала в SHT-файле
- Собственный массив времени
- Массив измеренных значений
- Метаданные канала

Для каждой записи проверяется, что массив времени является одномерным, содержит только конечные значения, строго возрастает и не имеет повторяющихся отсчетов. Число временных отсчетов должно совпадать с числом значений сигнала. Характерный шаг дискретизации канала определяется как медиана разностей между соседними моментами времени. Загруженные каналы объединяются в представление многоскоростного разряда. На этом этапе каждый сигнал сохраняется на собственной временной сетке: значения не интерполируются и не обрезаются. Загрузчик может прочитать заранее заданный набор каналов либо вернуть полный список имен, содержащихся в конкретном SHT-файле. После загрузки определяется опорный SXR-канал. Сначала по сигналу тока выделяется плазменный интервал. Затем для каждого доступного SXR-канала вычисляется отношение сигнал/шум:

`SNR = std(SXR на плазменном интервале) / (std(SXR до начала плазмы) + 10⁻⁸)`.

Опорным становится доступный SXR-канал с максимальным конечным значением SNR. При точном равенстве оценок предпочтение отдается номинально заданному каналу `SXR 50 mkm`. При формировании псевдоразметки и обучающих данных дополнительно требуется, чтобы максимальный SNR был не ниже 2. Если ни один SXR-канал не удовлетворяет этому условию, разряд не используется для автоматической разметки. Выбранный канал задает опорную временную сетку плазменного интервала, используется для оценки периода пилообразных колебаний и дает базовый блок из 16 признаков. Остальные SXR-каналы при этом не отбрасываются: они участвуют в многоканальном подтверждении событий и дают собственные признаки. Например, в разряде `sht42465` опорным был автоматически выбран `SXR 15 мкм`, а не `SXR 50 mkm`, поскольку его отношение сигнал/шум оказалось выше. Таким образом, результатом загрузки является не единая матрица с заранее предполагаемой общей сеткой, а набор исходных каналов и явно выбранная опорная шкала, относительно которой выполняется следующий этап обработки.

## Выравнивание каналов и обработка пропусков

Для вычисления многоканальных признаков дополнительные диагностические сигналы приводятся к временной шкале опорного SXR-канала внутри плазменного интервала. Это обеспечивает сопоставимость значений разных каналов около одного и того же кандидата. Реализованы три способа выравнивания:

- Линейная интерполяция между двумя соседними отсчетами исходного сигнала
- Выбор ближайшего по времени отсчета
- Использование последнего известного значения, предшествующего требуемому моменту

Способ задается в профиле отдельно для каждого диагностического канала. Для каналов полного профиля используется линейная интерполяция. Если исходный канал уже содержит все требуемые моменты времени, его значения выбираются напрямую без повторной интерполяции. Интерполяция разрешается только внутри фактического временного диапазона исходного сигнала. До первого и после последнего зарегистрированного отсчета экстраполяция не выполняется. Допустимая ширина разрыва между соседними исходными точками ограничивается величиной `2.5 × source_dt`. Поэтому для канала с шагом 10 мкс интерполяция возможна через разрыв не более 25 мкс, а при большем разрыве соответствующая точка считается отсутствующей. Для каждого выровненного канала сохраняются:

- Значения на опорной временной сетке
- Логическая маска валидности каждого значения
- Исходный шаг дискретизации
- Использованный метод выравнивания
- Признак наличия канала в исходном SHT-файле
- Признак того, выполнялся ли пересчет временной сетки

Если ожидаемого канала нет в разряде, для него создается запись-заполнитель с требуемой временной сеткой, значениями `NaN` и полностью нулевой маской валидности. Отсутствие канала тем самым не смешивается с физическим нулевым значением сигнала и не изменяет расположение остальных признаков в итоговом векторе. После выравнивания порядок каналов совпадает с порядком полного профиля. Для каждого канала можно определить долю валидных отсчетов, а при подготовке разряда отдельно фиксируются каналы, использованные напрямую, интерполированные каналы и отсутствующие каналы. Это позволяет контролировать качество многоканальных данных до вычисления признаков.

## Формирование обучающей и проверочной частей

До построения псевдоразметки из каталогов `easy`, `medium`, `hard` и `notSaw` формируется единый список разрядов. Для каждого файла сохраняются идентификатор разряда, категория сложности и относительный путь к SHT-файлу. Дополнительно проверяется, что один и тот же номер разряда не встречается в нескольких категориях. Разделение выполняется по целым разрядам, а не по отдельным событиям. Все события одного разряда попадают только в одну часть данных. Это исключает ситуацию, при которой похожие фрагменты одного и того же временного ряда одновременно используются и при подготовке классификатора, и при его проверке. Доля validation задана равной 20 %. Разделение выполняется отдельно внутри каждой категории, поэтому и в обучающей, и в проверочной части сохраняются разряды разной сложности.

Всего в список вошло 56 разрядов. Они разделены следующим образом:

- `easy`: 17 разрядов в обучающей части и 4 в validation
- `medium`: 14 разрядов в обучающей части и 3 в validation
- `hard`: 10 разрядов в обучающей части и 2 в validation
- `notSaw`: 5 разрядов в обучающей части и 1 в validation

Итого обучающая часть содержит 46 разрядов, а проверочная — 10. В validation вошли:

- `easy`: `sht44368`, `sht44370`, `sht46699`, `sht46710`
- `medium`: `sht41025`, `sht44337`, `sht44428`
- `hard`: `sht38811`, `sht44335`
- `notSaw`: `sht39499`

Сформированное разделение сохраняется непосредственно в файле псевдоразметки в отдельных массивах `train` и `validation`. Поэтому при последующей обработке не требуется заново случайным образом распределять разряды.

## Получение файла псевдоразметки

Под псевдоразметкой понимается автоматически полученный набор опорных событий. Псевдоразметка и кандидаты классификатора хранятся раздельно. Алгоритмический вейвлетный детектор формирует опорные события в `data/dataset/wavelet_pseudo_labels.json`, а POSR и CPD формируют более широкий набор возможных событий. Кандидат получает класс после сопоставления с ближайшим опорным событием. Для формирования псевдоразметки выполняются следующие действия:

1. Из SHT-файла загружаются пять предусмотренных SXR-каналов
2. Для каждого доступного SXR-канала оценивается отношение сигнал/шум
3. Каналы с отношением сигнал/шум ниже 2 не используются
4. Вейвлетный детектор независимо обрабатывает каждый оставшийся SXR-сигнал
5. Учитываются только события на установившемся участке тока плазмы
6. События из разных каналов, найденные в пределах 0,15 мс, объединяются
7. Событие считается подтвержденным, если его обнаружили как минимум два SXR-канала
8. События с поддержкой только одного канала сохраняются отдельно как неопределенные

Установившийся участок тока плазмы определяется после достижения 80 % характерного уровня и удержания этого уровня не менее 0,5 мс. Такое ограничение исключает ранние переходные участки разряда, на которых резкое изменение SXR может быть связано с набором тока плазмы. Для каждого подтвержденного события сохраняются абсолютное и относительное время, индекс на временной шкале плазменного интервала, оценка детектора, список подтвердивших SXR-каналов, их количество, отношение сигнал/шум и временной разброс отдельных срабатываний. Например, для разряда `medium/sht42465.SHT` в файле записано 48 подтвержденных и 39 неопределенных событий. Опорным автоматически выбран канал `SXR 15 мкм`, шаг его временной сетки равен 1 мкс, а оцененный период пилы составляет 1,521 мс. Ниже приведен сокращенный фрагмент реальной записи подтвержденного события:

```json
{
  "time_s": 0.151436,
  "relative_time_s": 0.03331,
  "score": 0.3963876734531133,
  "method": "multi_sxr_wavelet",
  "metadata": {
    "source_channels": ["SXR 127 мкм", "SXR 50 mkm"],
    "support_count": 2,
    "channel_snr": {
      "SXR 127 мкм": 13.0248,
      "SXR 50 mkm": 60.0902
    },
    "time_spread_s": 0.00014
  }
}
```

Событие подтверждено двумя SXR-каналами. Отдельные оценки времени отличаются на 0,14 мс, что не превышает установленное окно объединения 0,15 мс. В том же разряде имеется одноканальное событие:

```json
{
  "time_s": 0.143376,
  "score": 0.3659385089181064,
  "method": "multi_sxr_wavelet",
  "metadata": {
    "source_channels": ["SXR 127 мкм"],
    "support_count": 1,
    "time_spread_s": 0.0
  }
}
```

Оно сохраняется в массиве `uncertain_events`, поскольку найдено только на одном канале. Связь псевдоразметки с кандидатами можно показать на том же разряде. В файле POSR-кандидатов имеется событие со временем `0.151326 с`. Ближайшее событие псевдоразметки находится в `0.151436 с`. Расстояние между ними равно `0.00011 с`, поэтому кандидат получает положительную метку:

```json
{
  "time_s": 0.151326,
  "label": 1,
  "method": "multi_sxr_union",
  "closest_teacher_time_s": 0.151436,
  "distance_to_teacher_s": 0.00011,
  "label_source": "wavelet",
  "metadata": {
    "source_channels": ["SXR 127 мкм", "SXR 80 mkm"],
    "proposal_count": 2,
    "time_spread_s": 0.00003
  }
}
```

Разряды `notSaw` также присутствуют в файле. Например, запись для `notSaw/sht38596.SHT` имеет статус `labeled`, но содержит пустые массивы `events` и `uncertain_events`. Это явно задает отрицательный пример на всем рассмотренном разряде, а не означает отсутствие информации о нем. Полученный файл псевдоразметки содержит 1368 подтвержденных и 1040 одноканальных неопределенных событий. Успешно обработаны 55 из 56 разрядов. Разряд `notSaw/sht42062.SHT` получил статус ошибки, поскольку из его файла не удалось загрузить ни одного требуемого канала. Ошибка записана явно и не маскируется пустым списком событий. На данном этапе файл остается полностью автоматической псевдоразметкой. Экспертная проверка и исправление отдельных событий не включаются в результаты второй недели.
